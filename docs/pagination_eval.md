# 活页页数 vs LayoutEngine 页数

评测目标：对比三种页数来源，证明 **活页页数已与预览/PDF 对齐**，并量化旧几何估算的残余误差。

### 方法

- **几何估算**：`QTextDocument::size()` ÷ `contentBodyHeightPx`（旧双路径残余）。
- **活页(引擎)**：`EditorViewLayout` 的 `pageCount`，直接取 `LayoutEngine`。
- **LayoutEngine**：预览 / PDF / 打印同源。
- 纸张：A4 默认边距；字体 Helvetica 12pt（空文档除外）。
- 页缝：`LayoutPage::startDocPos` → `cursorRect`（文档偏移锚点）。

### 样例说明

| 样例 | 意图 |
|------|------|
| 空文档 / 短正文 | 基线：单页、无溢出 |
| 长纯文本×40 / ×80 | 纯文本跨页；几何估算易低估 |
| 标题+正文 | 混合块样式 |
| 含表格 | 小表（单页内） |
| 含图×4 | 大图原子块跨页 |
| 多页表×36行 | 表行原子跨页（不拆单元格） |

### 接受标准

| 指标 | 标准 |
|------|------|
| Δ活页（活页−引擎） | **必须为 0** |
| Δ几何（短样例） | ≤ 1 |
| Δ几何（长纯文本 / 含图 / 多页表） | ≤ 3 |

### 结果

| 样例 | 几何估算 | 活页(引擎) | LayoutEngine | Δ几何 | Δ活页 |
|------|--------:|----------:|-------------:|------:|------:|
| 空文档 | 1 | 1 | 1 | 0 | 0 |
| 短正文 | 1 | 1 | 1 | 0 | 0 |
| 长纯文本×40 | 3 | 4 | 4 | +1 | 0 |
| 长纯文本×80 | 5 | 8 | 8 | +3 | 0 |
| 标题+正文 | 1 | 1 | 1 | 0 | 0 |
| 含表格 | 1 | 1 | 1 | 0 | 0 |
| 含图×4 | 3 | 4 | 4 | +1 | 0 |
| 多页表×36行 | 3 | 6 | 6 | +3 | 0 |

**摘要**：8 / 8 样例 Δ活页=0；|Δ几何| 最大 = 3。

结论：活页与引擎页数一致；几何估算在长文/图/表上可差数页——说明为何预览与活页页数均应改走 LayoutEngine。
